# AGENTS.md

Данный файл определяет обязательные правила работы для любых ИИ-агентов (Codex, Claude, DeepSeek и других).

## Правила

* Перед началом работы обязательно ознакомиться с файлом `STYLE_GUIDE.md`.
* При создании или изменении страниц строго соблюдать требования к дизайну, описанные в `STYLE_GUIDE.md`.
* После создания новой таблицы проверить результат по чек-листу из `STYLE_GUIDE.md`. (раздел 12 строки 333-348)
* Максимально избегать дублирования функций, CSS и JavaScript-кода.
* Если для страницы требуется собственный CSS или JavaScript, создать отдельный файл и подключить его через `functions.php` с использованием `add_action('wp_enqueue_scripts', ...)`. Код подключения расположен примерно в районе 15-й строки файла.
* Перед созданием новой функции, класса или компонента убедиться, что аналогичная реализация уже не существует в проекте.
* Не изменять существующую функциональность без явной необходимости.
* По возможности использовать существующие компоненты, стили и утилиты проекта вместо создания новых.
* Соблюдать единый стиль именования файлов, функций, классов и переменных, принятый в проекте.
* Не оставлять неиспользуемый код, закомментированные блоки или временные отладочные конструкции.
* При внесении изменений изменять только те файлы и участки кода, которые непосредственно относятся к поставленной задаче.
* Если изменение может привести к нарушению обратной совместимости или затронуть существующий функционал, сначала предупредить об этом.
* После завершения работы проверить, что изменения не нарушили существующий функционал и соответствуют требованиям `STYLE_GUIDE.md`. (раздел 12 строки 327-342)
